    Evaluation rubric

    Which set is richer?

    A set is richer when it captures more of the image's vibe: more of the distinct facets of the feeling the image carries, each named more precisely.

    • Range first — does one set reach sides of the image's feeling the other misses?
    • Then specificity — where both touch a facet, which names it more precisely?

    Ignore: whether a vibe is true of the image (treat every vibe as true), how many vibes a set lists, and how long the phrases are. Near-synonyms count once.

    Choose Tie only when neither set is richer. Keys: 1 / 2 / t to choose, s to save, ← / → to move.
