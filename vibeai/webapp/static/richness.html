    Axis definitions

    Tag an atom with an axis when the atom's vibe claim is about that dimension — not merely compatible with it. An atom can touch several axes; one that touches none is left untagged.

      Applicability is judged from the image alone, before reading the atoms. Default every axis to applicable and mark N/A only when the image has essentially no content for it — a solo portrait has no interpersonal axis, an empty sky has no object axis. Environment, color, style and affect are properties of every photograph, so they can't be switched off.

      Coverage score = how many of the applicable axes are touched by at least one atom, out of the 11 minus the ones marked N/A. other is recorded but never counted, so scores stay comparable across images — use the reason box to say what dimension it was.
