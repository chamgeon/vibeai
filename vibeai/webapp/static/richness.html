    Evaluation rubric

    Coverage (per pool vibe)

    The target set is the vibes this representation named. The pool is what several independent representations found in the same image, each one already verified against the image — so a pool vibe is not in question, only whether the target set conveys it.

    Apply the witness test to each pool vibe, on its own:

    • Try to describe an image that fits every vibe in the target set but clearly does not fit the pool vibe.
    • If you can describe such an image → the pool vibe narrows the feeling further → Missed (distinct).
    • If every image fitting the target set would also fit the pool vibe → Covered (redundant).

    The witness image must be one an ordinary viewer would readily accept, not a contrived edge case built on a wording technicality. Judge each pool vibe against the target set only — never against other pool vibes, and never let one verdict influence the next. Two or more target vibes can jointly cover a pool vibe. A pool vibe that is in tension with the target set is Missed, not invalid.
